# Smart Expense Tracker

A Spring Boot + Thymeleaf project to manage daily expenses.

## Features

- Add Expense
- View Expenses
- Delete Expense
- Filter by Category
- Calculate Total Expense
- Category Total
- REST APIs
- Swagger Documentation

## Tech Stack

- Java 17
- Spring Boot 3.5
- Thymeleaf
- Bootstrap 5
- Maven
- Swagger OpenAPI

## Run

mvn clean install

mvn spring-boot:run

Open

http://localhost:8081

Swagger

http://localhost:8081/swagger-ui/index.html
